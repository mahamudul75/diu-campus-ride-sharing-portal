# DIU Campus Ride Sharing Portal — Project Overview

## 1. Project Introduction
The DIU Campus Ride Sharing Portal is a web-based platform designed exclusively for Daffodil International University students. It helps students find rides, share transportation, and connect with other students traveling to similar destinations.

## 2. Project Objectives
- Make campus-related transportation easier.
- Help students find shared rides.
- Reduce individual transportation costs.
- Provide a student-focused and trusted ride-sharing platform.
- Improve communication between ride providers and passengers.

## 3. Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- MySQL-compatible database (TiDB Cloud)

### Additional Technologies
- Leaflet for maps
- WebSocket for real-time communication
- REST API for client-server communication

## 4. Main Modules

### Authentication Module
Handles student registration, login, authentication, and account-related operations.

### Ride Management Module
Allows students to create, manage, search, and view available rides.

### Passenger Request Module
Allows students to submit ride requests and connect with suitable ride providers.

### Driver Management Module
Supports driver applications and administrative approval.

### Messaging Module
Provides communication features between students.

### Notification Module
Displays notifications related to user activities and ride updates.

### Administration Module
Provides administrative tools for managing users, rides, driver applications, and reports.

## 5. User Roles

- Student: Uses the platform to find rides or offer rides.
- Approved Driver: An eligible student approved to offer rides.
- Administrator: Manages platform operations and approval processes.

## 6. Project Scope
The portal is intended for DIU students and focuses on campus-related ride sharing. It combines ride management, passenger requests, communication, notifications, and administration in a single platform.

## 7. Conclusion
The DIU Campus Ride Sharing Portal aims to make student transportation more convenient through a centralized digital ride-sharing platform.
